# SmartOrder - Interfaz Gráfica

Proyecto desarrollado para la evidencia GA6-220501096-AA3-EV02, correspondiente al programa Análisis y Desarrollo de Software (ADSO).

## Descripción
SmartOrder es la solución de gestión para el establecimiento "Mr. Pks Pizzas". Esta interfaz tiene como objetivo optimizar la experiencia de usuario en la toma de pedidos y gestión de órdenes.

## Tecnologías Utilizadas
- **HTML5:** Estructura semántica de las vistas.
- **CSS3:** Diseño responsivo, paleta de colores y estilos visuales.
- **JavaScript:** Lógica de interacción básica del cliente.

## Estructura del Proyecto
- `index.html`: Página principal.
- `css/`: Hoja de estilos `styles.css`.
- `js/`: Archivos de lógica `app.js`.
- `assets/`: Recursos gráficos y logotipos.

## Instrucciones de uso
1. Descargue y descomprima la carpeta del proyecto.
2. Abra el archivo `index.html` en su navegador web preferido (Chrome, Edge o Firefox).
3. Navegue a través del menú superior para visualizar los diferentes módulos.
